# SQL Data Analytics Project

## Overview
This project focuses on analyzing structured data using SQL Server. It demonstrates how to explore datasets, identify patterns, and extract insights through well-structured SQL queries.

## Objectives
- Perform exploratory data analysis (EDA) using SQL.
- Apply analytical techniques to understand trends and patterns.
- Use advanced SQL features to generate meaningful insights.

## Analysis Approach
The analysis is organized into multiple stages:

- **Exploration**: Understanding data structure, dimensions, and measures.
- **Aggregation**: Summarizing data using metrics such as totals and averages.
- **Advanced Analysis**:
  - Ranking and comparison using window functions.
  - Segmentation of data into meaningful groups.
  - Cumulative calculations and time-based trends.
  - Part-to-whole analysis for contribution insights.

## Implementation Highlights
- Used aggregations (SUM, AVG, COUNT) to derive key metrics.
- Applied window functions (ROW_NUMBER, RANK) for ranking and comparisons.
- Built queries using CTEs for clarity and modularity.
- Generated structured outputs for customer and product reporting.

## Technologies
- SQL Server
- T-SQL

## Project Structure
/datasets -> Input datasets

/queries -> SQL analysis scripts

/results -> Output queries / derived insights

## Outcome
The project demonstrates the ability to transform raw data into meaningful insights using SQL, supporting data-driven decision-making.

## Key Learnings
- Writing structured and efficient SQL queries.
- Applying advanced SQL techniques for analysis.
- Interpreting data through aggregation and segmentation.
- Organizing analysis into clear and logical steps.
